components/sections/hero.tsx  weight, tracking and leading retuned


WHAT ELSE CHANGED
-----------------
The italic on "Intelligence" is gone. That was a serif move and Space
Grotesk has no italic worth using.

Headline is now medium weight instead of light, tracking is tighter
(-0.045em), and the lines sit closer together (0.95 leading). Serifs
want air; a geometric sans at display size wants the opposite. Loose
tracking is the single commonest reason a big headline reads cheap.


IF YOU WANT TO TRY THE OTHER TWO
--------------------------------
In app/layout.tsx, line 2, swap the import and the function name:

   Bricolage Grotesque:
      import { Bricolage_Grotesque, Geist } from "next/font/google";
      const spaceGrotesk = Bricolage_Grotesque({ ... });

   Instrument Sans:
      import { Instrument_Sans, Geist } from "next/font/google";
      const spaceGrotesk = Instrument_Sans({ ... });

Leave the variable name and everything else alone. Restart the dev
server after a font swap, Next caches font files.
