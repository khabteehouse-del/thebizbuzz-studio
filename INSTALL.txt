BizBuzz Studio - Phase 2 (Layout Shell)
=======================================

WHAT TO DO
----------
1. Extract this zip.
2. Copy the folders "app", "components" and "data" into:
      C:\BizBuzz\thebizbuzz-studio
3. Windows will ask to replace existing files. Choose "Replace the files
   in the destination". This is expected. It overwrites globals.css,
   layout.tsx and page.tsx, and adds the new component files.
4. Create the logo folder and drop logo.png in it:
      mkdir public\images\logo
5. Run:
      cd /d C:\BizBuzz\thebizbuzz-studio
      npm run dev
6. Open http://localhost:3000


FILES IN THIS PACKAGE
---------------------
app/globals.css                       brand tokens, base styles, section label
app/layout.tsx                        fonts, metadata, providers, nav, footer
app/page.tsx                          temporary placeholder page
components/layout/nav.tsx             fixed nav, scroll background, mobile menu
components/layout/footer.tsx          footer with brand, nav, contact
components/shared/smooth-scroll.tsx   Lenis momentum scroll
components/shared/cursor.tsx          custom cursor, pointer devices only
components/shared/magnetic.tsx        magnetic wrapper for CTAs
data/site.ts                          nav links, contact, socials


WHAT YOU SHOULD SEE
-------------------
- Dark background, off-white text
- Logo top left, nav links top right, blue "Start a project" button
- Nav is transparent at the top, gains a blurred dark bar once you scroll
- Scrolling feels weighted, not snappy (that is Lenis)
- A small dot follows the cursor, a ring lags behind and grows on links
- Clicking a nav link glides to that section
- Five placeholder sections, then the footer
- Narrow the window: nav collapses to a hamburger, cursor disappears


IF SOMETHING BREAKS
-------------------
"Module not found: motion/react"
   npm install motion

"Cannot find module lenis"
   npm install lenis

Logo does not appear
   Check the file is at public\images\logo\logo.png exactly.

Colors look wrong or unstyled
   globals.css did not get replaced. Copy it again and confirm the
   file at app\globals.css starts with @import "tailwindcss";

Fonts look like Times New Roman
   Newsreader failed to download. Check your internet, restart dev server.
